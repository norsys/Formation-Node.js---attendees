# Node.js - Support d'exercices (formation JavaScript)

## Présentation

Ce dépôt sert de base d'exercices pour les participants d'une formation JavaScript + Node.js.

Cette branche ne contient aucun exercice : chaque exercice est disponible sur sa propre branche. Pour démarrer un exercice, récupérez la branche correspondante indiquée par le formateur :

```
git checkout <nom-de-la-branche>
```

## Prérequis

### Node.js

Version 20 minimum requise, idéalement la dernière version LTS.

L'installation via [NVM](https://github.com/nvm-sh/nvm) (macOS/Linux) ou [nvm-windows](https://github.com/coreybutler/nvm-windows) (Windows) est recommandée plutôt que l'installeur officiel, afin de faciliter la gestion des versions de Node.js :

```
nvm install --lts
nvm use --lts
```

### Git

Voir la [documentation officielle d'installation de Git](https://git-scm.com/downloads).

### Docker

Voir la [documentation officielle d'installation de Docker](https://docs.docker.com/get-docker/).

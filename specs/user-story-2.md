# User story 02 : reapprovisionner un produit

> En tant qu'utilisateur de la CLI, je veux augmenter le stock d'un produit afin de refleter une reception de marchandises.

La quantite est un entier strictement positif.

# Criteres d'acceptation

- le produit cible existe ;
- la quantite est un entier positif ;
- le stock final est augmente ;
- la date de mise a jour evolue ;
- le catalogue est persiste apres une operation valide.
